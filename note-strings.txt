String
------

- sequence of characters
- string is immutable & array is mutable
        eg:-    str = 'Luminar'
                console.log(str[2])
                str[2] = 'q'
                console.log(str)

                arr = ['L','u','m','i','n','a','r']
                console.log(arr[2])
                arr[2] = 'q'
                console.log(arr)

Naming Convention
-------------------
        1) camel case - myVariableName
        2) pascel case - MyVariableName
        3) snake case - my_variable_name
        4) kebab case - my-variable-name 
        5) screaming snake case - MY_VARIABLE_NAME 


Methods
--------

1) startsWith() - it checks whether a string starts with a specific character
            - this method is case sensitive
            - returns a boolean value

2) endswith() - it check whether a string ends with a particular sequence
            - case sensitive
            - return a boolean value

3) toUpperCase() - to convert a string into capital letters

4) toLowerCase() - to convert a string into small letters

5) substring() - to create a sub string from a given string
                - take only +ve values
                - ending index will be excluded

        syntax
        -------
        string.substring(start , end)


6) slice(start,end) - to get a small portion of a string
                    - ending index will be excluded
                    - also accept negative values

7) trim() - helps to remove a space in the ends(start , end) in a given string
          
8) replace() - it replaces the first matching search item
                syntax
                ------
                string.replace(searchValue, replaceValue)

9) replaceAll() - it replaces all matching search item in the string

10) array.from() - to get all character of a string as array

11) split(separator) -  divides the string based on the separator and return a new array
